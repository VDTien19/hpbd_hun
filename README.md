## 🌷 Giới thiệu

**Một chương mang tên Hương** là một website chúc mừng sinh nhật mang tính cá nhân, được xây dựng như một hành trình tương tác thay vì một tấm thiệp điện tử thông thường.

Mỗi trang là một phần của câu chuyện: bắt đầu bằng lời chào, tiếp nối bằng những lời chúc, vài câu hỏi, những món quà bất ngờ và kết thúc ở một không gian kỷ niệm để người nhận tự do khám phá.

Đây không phải một sản phẩm thương mại. Nó là một món quà được làm bằng code, thời gian và rất nhiều sự để tâm. ♡

## ✨ Trải nghiệm

| Chặng | Nội dung |
| --- | --- |
| **Home** | Mở đầu với lời chào sinh nhật và lời mời bước vào câu chuyện. |
| **Wishes** | Những lời chúc dành riêng cho Hương. |
| **Questions** | Một vài câu hỏi nhỏ về cảm xúc, dự định và điều ước. |
| **Gifts** | Chọn hộp quà, gặp những bất ngờ vui nhộn, khám phá ba món quà và thổi nến sinh nhật. |
| **Memories** | Bước vào thế giới kỷ niệm 3D với những khối ảnh có thể tương tác và một bí mật cuối cùng. |

**Hành trình:** `Home → Wishes → Questions → Gifts → Memories`

## 🎨 Thiết kế & tương tác

- **Pastel, dreamy & kawaii:** tông hồng, kem và xanh dịu nhẹ; nơ, trái tim, ngôi sao cùng các chi tiết trang trí thủ công.
- **Kể chuyện theo từng bước:** mỗi màn hình có một vai trò trong trải nghiệm sinh nhật.
- **Hiệu ứng tương tác:** chọn quà, mở quà, thổi nến và chuyển cảnh.
- **Không gian kỷ niệm 3D:** các khối lập phương chứa ảnh, chuyển động nhẹ nhàng và tương tác xem ảnh.
- **Responsive:** hướng đến trải nghiệm trên cả điện thoại và máy tính.

## 🛠️ Công nghệ

- **React** — xây dựng giao diện và quản lý tương tác.
- **Vite** — môi trường phát triển và đóng gói ứng dụng.
- **SCSS Modules** — tổ chức style theo từng trang và thành phần.
- **3D / animation** — phục vụ các hiệu ứng và không gian kỷ niệm, tùy theo thư viện được cấu hình trong dự án.

## 🚀 Chạy dự án ở máy cá nhân

Yêu cầu: **Node.js** và **npm**.

```bash
# Cài đặt dependencies
npm install

# Chạy môi trường phát triển
npm run hunhun

# Build bản production
npm run build

# Xem trước bản build
npm run preview
```

Sau khi chạy `npm run hunhun`, mở địa chỉ localhost được Vite hiển thị trong terminal.
